### What's unique about this Lab compered to the previous ones? 
#### With JavaScript, modifications happen instantly on the exact same structure currently open in the browser's memory (known as the DOM). This allows us to update the user interface in real-time without communicating with the server at all. Therefore, there is no need for a new HTTP request or to load another HTML file, which eliminates page refreshes.
